# Домены в IP-сети

Программа берёт список доменов, узнаёт их IP-адреса через DNS и собирает
адреса в сети. Кроме того, IP-адреса можно добавлять вручную.

## Файлы в папке

- `*.har` — файлы, которые Chrome сохраняет из консоли разработчика (вкладка
  Network). Лежат в корне папки. `run.sh` превращает их в `urls.txt` и удаляет.
- `extract-har.py` — заменяет `urls.txt` всеми ссылками из `.har`-файлов и
  удаляет прочитанные `.har`.
- `urls.txt` — список ссылок (URL). Создаётся из `.har`, после работы
  удаляется. Не входит в git.
- `domains.txt` — список доменов, по одному на строку. Это входные данные.
  Не входит в git.
- `ips.txt` — список IP-адресов. Его заполняет программа или вы вручную.
- `networks.txt` — итоговый список сетей IPv4 размером `/20`.
- `cidrs.txt` — точные диапазоны адресов, создаётся `aggregate-cidrs.py`.
- `run.sh` — запускает определение IP по доменам в фоновом режиме.
- `extract-domains.py` — берёт домены из `urls.txt` и добавляет их в `domains.txt`.
- `resolve-domains.py` — скрипт, который определяет IP по доменам.
- `aggregate-cidrs.py` — собирает `cidrs.txt` из `ips.txt`.
- `update-networks.py` — переводит IP-адреса из `ips.txt` в сети `/20` и
  добавляет новые в `networks.txt`.

## Что нужно

- Python 3
- утилита `getent` (обычно есть в Debian и Ubuntu, входит в пакет `libc-bin`)

Устанавливать ничего через `pip` не нужно.

## Сценарий 1: узнать IP по доменам

1. Есть три способа указать домены:
   - Сохраните из Chrome файл `.har` (вкладка Network, Save all as HAR) и
     положите его в корень папки. При запуске `run.sh` все ссылки из него
     попадут в `urls.txt`, файл `.har` будет удалён. Если `.har` не удалось
     прочитать, он остаётся и выводится предупреждение.
   - Или положите ссылки в `urls.txt`, по одной в строке. Домены из них попадут
     в `domains.txt` при запуске `run.sh`. Затем `urls.txt` удаляется. Для
     каждого домена добавляются две записи: `example.com` и `www.example.com`.
   - Или откройте `domains.txt` и впишите домены, по одному в строке.

   Строки, которые не являются ссылками `http://` или `https://`, пропускаются.
   IP-адреса вместо доменов тоже пропускаются. Если `urls.txt` нет, этот шаг
   пропускается.

2. Запустите сбор IP:

   ```bash
   chmod +x run.sh
   ./run.sh
   ```

3. Чтобы смотреть за ходом работы, выполните:

   ```bash
   tail -f resolve.log
   ```

   Когда в логе появится строка `Finished`, работа закончена.

4. Сети уже обновляются автоматически, когда сбор IP завершён. Если нужно
   обновить их вручную, выполните:

   ```bash
   python3 update-networks.py
   ```

5. По желанию соберите точные диапазоны:

   ```bash
   python3 aggregate-cidrs.py
   cat cidrs.txt
   ```

## Сценарий 2: добавить IP вручную

1. Откройте `ips.txt` и добавьте адреса, по одному в строке.
2. Запустите:

   ```bash
   python3 update-networks.py
   ```

3. Новые сети добавятся в конец `networks.txt`. Перед ними появится
   строка-комментарий вида `# added 2026-11-24 22:40:00`.

## Важно

- **Не запускайте `run.sh`, если в `ips.txt` есть ваши ручные адреса.**
  Программа определения IP перезаписывает `ips.txt`. Сделайте копию файла
  заранее.
- `networks.txt` только дополняется. Если вы удалили адрес из `ips.txt`,
  его сеть останется в `networks.txt`. Чтобы убрать её, удалите строку вручную.
- Адреса IPv6 и неправильные строки пропускаются. В `networks.txt`
  попадают только IPv4-сети.
- Результаты DNS со временем могут меняться. Запускайте сбор заново, если
  нужны свежие данные.
